Findings

1. HEVC Main10 is advertised but cannot initialize on the tested hardware path.
   All 30 hashes differed from the P010 reference; the driver failed context
   initialization and FFmpeg fell back to software yuv420p10le. This is not
   evidence of hardware pixel corruption. strace confirms CAPTURE VIDIOC_S_FMT
   requested P010 and the kernel returned NV12. The driver rejects that format
   change. No Main10 BeginPicture calls were observed.
   Evidence: /tmp/libva-quality-20261001/codecs/hevc10-30.log
             /tmp/libva-quality-20261001/main10-ioctl.log
   Follow-up: investigate P010 negotiation timing and gate advertisement on
   usable decode support, not merely format enumeration. Verifiers should
   reject software fallback explicitly before doing checksum comparisons.

2. HEVC synthesis accepts tile counts exceeding the fixed VA arrays.
   A zero-initialized HEVC picture with 320x240 dimensions, tiles enabled,
   and num_tile_columns_minus1 = column_width_minus1.len()+1 returns Ok.
   The writer signals the excessive count while iter().take() emits only the
   available array entries, producing inconsistent syntax. This should be
   rejected before synthesis/submission. No hardware submission was made for
   malformed inputs.
   Location: rust/src/h265/synth.rs::synthesize_parameter_sets / synthesize_pps
   Evidence: /tmp/libva-quality-20261001/hevc-invalid-tiles.log
   Reproduce: ./tools/verify-host-stress.sh
   The new regression assertion intentionally remains failing until fixed.

3. Export-fd drop test is unreliable under parallel execution.
   surface_export::tests::dropping_surface_closes_tracked_export_fds failed
   with 16 test threads: fcntl returned 1 instead of -1 after dropping OwnedFd.
   Another concurrent test may reuse the closed numeric fd before fcntl runs.
   This is a test race, not evidence of an fd leak. Verify EOF via a pipe/socket
   whose final writer is owned by the surface, rather than probing a stale fd.
   Evidence: /tmp/libva-quality-20261001/unit-tests.log
   The failure was intermittent; a later run did not reproduce it.
