   Regression: a server acknowledging every command but retaining the same

   forward decoded/playback progress, with tolerance based on actual keyframe
   landing rather than exact target time. Continue rejecting fallback, lost
   properties, mismatched request IDs and disconnects. This still does not
   establish pixel parity at every target; that needs independent frames.
