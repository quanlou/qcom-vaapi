Changes in this follow-up

- Export-fd regression now verifies EOF on a Unix socket after the last tracked
  peer is dropped. It cannot mistake a newly reused numeric fd for a leak.
- EndPicture waits for publication when the target was already exported.
  Stable exported allocations are filled by a CPU copy, which has no decode
  completion fence for implicit-sync GL importers. The driver mutex is released
  before waiting, so submission on another thread can continue.
- Stable-slot CPU writes keep a CLOEXEC allocation handle, wait for prior
  importer fences with bounded poll, and bracket CPU access with dma-buf SYNC.
  Failed cache maintenance, copies, and undersized destinations propagate errors;
  a failed stable copy cannot publish stale contents as a completed frame.
  This is an implemented GL correctness fix requiring fresh hardware validation,
  not a claim that the previously missing GL frame is proven recovered.
- Profile discovery belongs to each initialized driver rather than a leaked
  process-global cache. Failed discovery advertises no invented H.264 support.
  Configuration attribute counts and null lists are bounded and validated.
- H.264 now emits custom VA raster-order quantization matrices in PPS diagonal
  scan order, including wrapped signed deltas. Flat defaults retain historical
  header bytes. Invalid zero scaling values and truncated IQ buffers fail.
  Host tests reconstruct 4x4 and 8x8 raster matrices independently. Hardware
  custom-matrix parity still needs qualification alongside the existing fixtures.
- Strict GL qualification requires exact frame count and display order, rejecting
  extra corrupt frames as well as missing frames. Reference download requires a
  hardware frame, so software fallback cannot satisfy the GL gate.
- Natural EOS compares against an independently decoded complete reference.
  Sanity decodes must contain one actual frame; header-only output cannot pass.
- Seek commands require matching request-ID success replies and active
  vaapi-copy decoding. Events, rejected commands, and disconnections cannot
  count as seeks. The shell propagates IPC-controller failure as well as player
  failure, disallows software fallback, and rejects a skipped mixed-resolution
  seek phase in strict mode. These checks prove accepted seek commands and
  decoder selection; they do not establish pixel parity for every seek target.
- The production gate runs defensive/concurrent stress, serializes hardware
  qualification, rejects missing devices and observed kernel bugs/power cycles,
  and refuses unqualified experimental AV1. CI includes host stress.
- Prior Main10 provisional-format negotiation and HEVC tile validation fixes
  are preserved. Source translation and kernel queue contracts are unchanged
  by this follow-up outside the completion/copy fixes described above.
