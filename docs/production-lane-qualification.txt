Limits

The provenance manifest detects changed supplied inputs at checkpoints; it is
not an authenticity attestation or a substitute for freeze/serial qualification.
It does not establish firmware identity or prove a patch is booted. Automatically
created codec samples should be prepared first; adding them to an already bound
fixture directory intentionally fails that attempt. Missing devices, kernel
patch boot evidence, strict GL/real-browser results, long-GOP recovery and full
AV1 parity cannot be closed by these host tests.
